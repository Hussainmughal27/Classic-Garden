# Classic Gardening Website (GreenHaven)

A classic, fully responsive, and elegant website for gardening and landscaping services. Designed for seamless viewing across PCs, tablets, and mobile devices.

---

## 📁 Project Structure

```
ClassicGarden/
│
├── index.html    # Main HTML structure
├── style.css     # CSS design, themes, and mobile responsive rules
├── script.js    # JavaScript for mobile navigation & form interaction
└── README.md     # Instructions on how to edit and view the website
```

---

## 🛠️ How to Open and Edit in VS Code

### Method 1: Open directly from Terminal
Run this command in your terminal:
```bash
code /home/hussain/Desktop/ClassicGarden
```

### Method 2: Open from inside VS Code
1. Launch **Visual Studio Code**.
2. Click **File** > **Open Folder...**
3. Select the folder: `/home/hussain/Desktop/ClassicGarden`
4. Click **Open**.

---

## 🌐 How to View the Website

### Option A: Open directly in your Web Browser
Double-click on `index.html` inside the `Desktop/ClassicGarden` folder, or right-click `index.html` -> **Open With** -> **Web Browser**.

### Option B: Use Live Server extension in VS Code
1. Install the **Live Server** extension in VS Code.
2. Open `index.html`.
3. Click **"Go Live"** at the bottom-right status bar of VS Code.

## 🌿 Features Included
- **Classic Design:** Deep forest green theme with warm gold accents and serif typography (`Playfair Display` & `Lora`).
- **Fully Responsive:** Custom mobile navigation bar (hamburger menu) and flexible grids adapt seamlessly to phones, tablets, and desktop displays.
- **Interactive Sections:**
  - Hero Header with Call-to-Action buttons.
  - Heritage & Story Section.
  - Interactive Services Cards.
  - Botanical Gallery with hover overlays.
  - Garden Journal (Tips & Advice).
  - Consultation Contact Form with real-time submission feedback.
